# DroidDeck 手机迁移版设计

用户于 2026-10-14 确认实施。独立包名 com.droiddeck.migration，与官方版并存。完整 DroidDeck 源码基线 10ef8c4bd62b21872fc13382a808cb0f2f117b26。

手机选择 TAR 即可离线恢复私有 files 持久数据，另选择旧 settings-backup.json。后续备份包含设置元数据，做到单个 TAR 导入。前台服务执行单线程流式校验与解包，展示阶段/字节进度，校验路径、条目数、总解包大小、可用空间。保持 Linux 链接与执行权限；禁止穿越路径及通过链接写入。解包后核对 Linux gamescope、session 脚本、版本和 Steam 目录。临时目录与 files 在同一应用分区，恢复前必须无游戏会话；完整验证后用可恢复事务切换目录，失败保留旧数据。应用启动时首先恢复未完成的事务。权限与设置导入由本应用 UID 写入，重建挂载目录。

普通设置按类型导入，过滤设备相关路径、调试授权和设备限制标记；账号密钥不迁移。官方更新不能覆盖本版本，更新入口明确说明。备份在无游戏会话时创建，过滤运行目录、缓存、套接字和加密商店凭据；设置随包附带。用户通过安卓文件选择器选择输入/输出位置。既有 8.19 GiB TAR 无内置清单，用其关键文件验证并支持可选 SHA256；新导出带清单与逐文件 SHA256，恢复检查。

安装测试不替换官方版。验证危险归档、截断、链接、权限、回滚与中断恢复；完整手机导入测试先核对空间并限制到一项任务，保持原用户数据。最终交付 APK、同签名可更新的源代码及操作说明；未做目标手机游戏验证的部分明确注明。
